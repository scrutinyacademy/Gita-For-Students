# GITA FOR STUDENTS

**Ancient Wisdom for Modern Student Life**

A mobile-first Bhagavad Gita learning and reflective guidance platform for students.

## Principles
- Scripture and modern interpretation are clearly separated.
- No fabricated quotations attributed to Krishna.
- Guidance always points back to a cited Bhagavad Gita verse.
- Crisis/medical/safety situations direct users to appropriate real-world help; spiritual material is supplementary.

## Planned experience
- Natural-language guidance search
- Emotion and student-problem discovery
- Complete Bhagavad Gita reader (18 chapters)
- Verse search, bookmarks, daily wisdom
- Student life, relationships, life questions, food & lifestyle guidance
- Personal journal stored locally
- 25-minute study/focus mode
- Gita knowledge quiz
- Responsive Krishna-inspired interface

## Text/data policy
The project will use verified, redistributable source text. Sanskrit/transliteration/translation provenance and licensing will be documented alongside the final dataset. Modern student explanations will be labeled as interpretations rather than quotations.

## Status
Repository initialized. Website implementation and validated scripture dataset are being built.
